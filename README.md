# Astrostatistics for Observational Cosmology

This repository contains code written as part of coursework for the MASS course Astroinformatics – Astrostatistics and Machine Learning in Observational Astronomy in the University of Belgrade. 

Instructor: Prof Dr. A. Kovačević

The aim of this repository is to apply statistical methods to astronomical observations, focusing on data exploration, uncertainty analysis, and cosmological parameter estimation.

### Data

The main datasets used in the exercises include:

* Pantheon+: Type Ia supernova observations used to study cosmological expansion and estimate cosmological parameters.
* SDSS-RM: Light curves of active galactic nuclei (AGN), used to explore observational cadence, variability, and data structure.

### Repository Structure

The repository is organized into laboratory notebooks covering different topics. Each notebook contains the code, explanations, figures, and results for the corresponding exercise. 

### Laboratory Exercises

**Lab 1 – Anatomy of Real Cosmological Data**

Exploration of the Pantheon+ and SDSS-RM datasets, focusing on data structure, measurement uncertainties, repeated observations, and observational biases.

**Lab 2 – Real Hubble Diagram: Residuals, Bootstrap and Statistical Evidence**

Analysis of Type Ia supernova observations using a reference cosmological model. The exercise focuses on residuals, bootstrap methods, and statistical tests to evaluate differences in the data.

**Lab 3 – Building a Cosmological Likelihood**

Estimation of the matter density parameter $\Omega_m$ using Pantheon+ supernova observations and a flat ΛCDM model. The analysis includes likelihood calculations, parameter estimation, and uncertainty analysis.

**Lab 4 – Bayesian Cosmology**

Bayesian estimation of $\Omega_m$ and $M_B$ using Pantheon+ supernova observations and a flat ΛCDM model. The analysis includes posterior distributions, credible intervals, prior sensitivity, and residual diagnostics.
